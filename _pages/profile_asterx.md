
---
title: AsterX
---
**AsterX** is a next-generation, GPU-accelerated GRMHD code for dynamical spacetimes, built on CarpetX/AMReX within the Einstein Toolkit. It supports high-resolution shock capturing, robust primitive variable recovery, tabulated EOS, and utilities for masks/seeding/analysis — targeting strong scaling on leadership-class systems.

- Repo: <https://github.com/EinsteinToolkit/AsterX>
- Focus: BNS mergers, post-merger remnants, jets, kilonovae
